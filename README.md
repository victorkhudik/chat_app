# Web Chat (React + GREEN-API)

Современный, модульный веб-клиент для WhatsApp, построенный на базе **React**, **Tailwind CSS** и **GREEN-API**. Приложение разделено на независимые инкапсулированные компоненты с глобальным управлением состоянием и авторизацией через React Context.

---

## 🚀 Основные возможности

* **Авторизация по GREEN-API**: Быстрый вход по `idInstance` и `apiTokenInstance` с предварительной проверкой состояния инстанса.
* **Модульная архитектура**: Интерфейс разделен на изолированные компоненты (`Sidebar`, `ChatWindow`, `Auth`) с вынесенной локальной логикой.
* **Глобальный стейт (Context API)**: Управление активной сессией и выбранным чатом без избыточного проброса пропсов (prop drilling).
* **Сохранение сессии**: Автоматическое восстановление выбранного чата и данных авторизации после перезагрузки страницы (`localStorage`).
* **Динамический список чатов**: Автоматическое обновление списка чатов при получении новых сообщений или создании нового чата по номеру телефона.
* **Поиск чатов**: Быстрая фильтрация контактов и чатов по имени или идентификатору.
* **История переписки**: Защищенная от дублирования загрузка истории сообщений с автопрокруткой к последнему сообщению.

---

## 🛠 Технологический стек

* **Frontend**: React (Hooks, Context API), Tailwind CSS
* **API**: GREEN-API (`fetch`, REST API, Webhooks polling)
* **Инструменты хранилища**: `localStorage` для сохранения учетных данных и активного чата

## ⚙️ Установка и запуск

1. **Клонируйте репозиторий**:
   ```bash
   git clone <ссылка-на-репозиторий>
   cd <название-папки-проекта>
   ```

2. **Установите зависимости**:
   ```bash
   npm install
   ```

3. **Запустите проект в режиме разработки**:
   ```bash
   npm run dev
   ```

4. Откройте приложение в браузере по адресу, указанному в терминале (обычно `http://localhost:5173`).

---

## 🔑 Использование

1. Перейдите в свой личный кабинет **GREEN-API** (`https://green-api.com/`).
2. Скопируйте **`idInstance`** и **`apiTokenInstance`**.
3. Введите их на экране входа в приложении.
4. Выберите существующий чат из списка слева, воспользуйтесь поиском или нажмите кнопку **«+ Чат»**, чтобы начать новый диалог по номеру телефона (например, `375291234567`).
